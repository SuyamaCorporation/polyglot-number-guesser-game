# Polyglot Number Spelling Guesser Game

## 概要
1〜100の数を12言語で表示し、言語名・数値・単語を当てる多言語数字クイズゲーム。

## 機能
- 12言語対応: English, French, German, Spanish, Italian, Portuguese, Japanese, Chinese, Russian, Arabic, Hindi, Swahili
- 3つのゲームモード:
  1. **Guess Language**: 数字の単語を見て言語を4択で選ぶ
  2. **Type the Word**: 数と言語名を見て単語を入力する
  3. **Guess the Number**: 数字の単語を見て数値を4択で選ぶ
- スコア・ストリーク・ベストストリーク・正答率の追跡
- 言語別正答率バー表示
- 数字参照テーブル（折りたたみ表示）
- localStorageによる進捗保存

## 使い方
1. モードタブで出題方式を選択
2. 表示された情報に基づいて回答
3. Nextボタン（またはスペースキー）で次の問題へ
4. Language Accuracyパネルで苦手言語を確認
